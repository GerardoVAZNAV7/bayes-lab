# Bayes Lab

App en Vue 3 + Vite para practicar: Naive Bayes (con y sin suavizado de Laplace), discretización,
función de densidad (media, varianza, desviación estándar, NORM.DIST), matriz de confusión y métricas.

## Local
    npm install
    npm run dev

## Vercel
1. Sube la carpeta a un repo de GitHub e impórtalo en vercel.com (detecta Vite solo), o
2. `npx vercel` desde esta carpeta.

Build: `npm run build` · Output: `dist`
Para agregar problemas edita `src/data/problems.js`.
